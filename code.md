# MLSMTP

## Instructions
### Running the program
To run the program, run the `mlsmtpnewinstance` file
to initialize config in a given directory. Then, run
`mlsmtpd --conf <path>` where `<path>` is the path to
`default.json` in the directory.
### Input
Input can be provided in three ways:
#### Submitted emails
To submit emails, connect an email client to the server
on the configured port. Then, you can send an email to
the server, submitting it via API. Alternatively, you
can send an email to an address where this server is
specified in the MX record, such that another server
provides input via API.
#### Config files
Input can be provided via config files. These are the
various JSON files created when you make a new instance.
Input is provided my modifying them according to what is
needed such that the program executes properly.
#### Queue and list commands
Input can be provided via the `mlsmtpqueue` and `mlsmtplist`
commands. These commands allow you to remove and modify
the contents of the mail queue as specified in the help
menu. Additionally, you can use the `mlsmtplist` command to
add and remove email lists and addresses to and from those
lists according to their help menus.
### Output
Output can be provided in two ways:
#### Sent emails
Output can be given in the form of emails delivered. These
emails can originate either from users and servers, or as
errors generated by the server. They can be delivered locally,
to a local storage option specified, or remotely, using SMTP
to deliver emails via API to an external server.
#### Logs
When you run any of the mlsmtp executables, they will provide
constant log output according to the settings. This will contain
information on the status, operation, and actions of the server
or the program you ran. An example is below:

# Sqlite3 Adapter
# This allows for interface with an Sqlite3 database

module SMTPServer
  module Database
    class SQLite3Adapter
      # Create a new adapter with settings from
      # default.json
      def initialize(settings)
        # Configure the settings
        @path = settings["path"]
        @setup_file = settings["db_setup"]
        @busy_timeout = settings["busy_timeout"]

        # Initialize the database
        initialize_sqlite

        # Setup the database with the default template
        setup_database if settings["autocreate_db"]
      end

      # Method to execute SQL in the database
      def exec_sql(*sql)
        @database.execute *sql
      end

      # Method to set up the database
      def setup_database
        @database.execute_batch File.read(@setup_file)
      end

      private

      # Method to set the database busy timeout
      def set_busy_timeout(timeout)
        exec_sql("PRAGMA busy_timeout = #{timeout};")
      end

      # Method to initialize the Sqlite3 database object
      def initialize_sqlite
        @database = SQLite3::Database.open @path
        set_busy_timeout(@busy_timeout)
      end
    end
  end
end

# SSL Certificate and Key handler class

module SMTPServer
  module SSL
    class Certificate
      # All loaded cert/key pairs
      @@certificates = {}

      # Create a new keypair
      def initialize(name="cert", certificate: nil, key:)
        # Set the name
        @name = name

        # Get the key as an OpenSSL::PKey::RSA object
        @key = key.is_a?(String) ? OpenSSL::PKey::RSA.new(key) : key

        # Only execute if a certificate is given
        if certificate
          # Get the certificate as an OpenSSL X509 Certificate
          @certificate = certificate.is_a?(String) ? OpenSSL::X509::Certificate.new(certificate) : certificate

          # Create an SSL Context with the cert and key given
          @context = OpenSSL::SSL::SSLContext.new
          @context.cert = @certificate
          @context.key = @key
        end

        # Add it to the main certificate list
        @@certificates[@name] = self
      end

      # Delete the current cert
      def destroy
        @@certificates.delete(@name)
      end

      # Get the certificate by name k
      def self.[](k)
        @@certificates[k]
      end

      # Set the certicicate with name k to value v
      def self.[]=(k, v)
        @@certificates[k] = v
      end

      # Get all certificates
      def self.all
        @@certificates
      end

      # Access and read the certificate, key, context, and name
      attr_accessor :certificate, :key, :context
      attr_reader :name

      # Load all certificates from the config file
      Config.active["certificates"].each do |name, info|
        # Get the certificate if it is set
        cert = info["cert_path"] ? File.read(info["cert_path"]) : nil
        # Get the key
        key = File.read(info["key_path"])

        # Create a new certificate
        new(name, certificate: cert, key: key)
      end
    end
  end
end

# SMTP Authorization handler
# Tests if the message is authorized by the rules
# set in default.json

module SMTPServer
  module Transport
    class AuthorizationHandler
      # Create a new authorization handler
      # with an SMTP client context
      def initialize(context)
        @context = context
      end

      # Handle authorization
      def handle_authorization
        # Test if it is authorized with the active Authorization
        # rules
        authorized = Authorization.active.authorized?(@context)

        # If message is authorized
        if authorized
          # Log that it is authorized and set the context as ready for data
          Logger.log "Authorization passed", origin: @context.logger_origin, verbosity: 5
          @context.data = :ready

          # Send a 250 215 OK response
          response = SMTP::Response.new(
            status: :positive_completed,
            category: :mail_system,
            message: "2.1.5 Ok"
          )
          @context.send_response(response)

        # If not authorized
        else
          # Log that authorization has failed
          Logger.log "Authorization failed", origin: @context.logger_origin, verbosity: 5, type: :warn

          # Send a 553 471 Authorization Error
          response = SMTP::Response.new(
            status: :negative_permanent,
            category: :mail_system,
            detail: 3,
            message: "5.7.1 Authorization Error"
          )

          @context.send_response(response)
        end
      end
    end
  end
end

# Remote delivery agent
# Delivers an email remotey to a server

module SMTPServer
  module Transport
    class RemoteDeliveryAgent
      # Define ports to attempt delivery to and the socket timeout
      @@attempt_ports = Config.active["external_transport"]["attempt_ports"]
      @@timeout = Config.active["external_transport"]["socket_timeout"]

      # Create the delivery agent with a destination, sender, message,
      # and origin
      def initialize(destination:, sender:,  message:, origin:)
        # Define the variables
        @message = message
        @destination = destination
        @servers = @destination.destination_servers
        @recipient_addr = @destination.destination_user
        @sender_addr = sender
        @origin = origin
      end

      # Attempt delivery
      def attempt_delivery
        @@attempt_ports.each do |port| # Do for each port to attempt
          @servers.each do |server| # Do for each server
            return true if deliver_to_server(server, port) # Return true if deliver_to_server() succeeds
          end
        end

        raise Errors::ServerRejectionError # Raise a ServerRejectionError if no server succeeded
      end

      # Allow the message, destination, servers, and recipient address are accessible
      attr_accessor :message, :destination, :servers, :recipient_addr

      private

      # Deliver the email to a given server
      def deliver_to_server(server, port)
        # Log the server we are trying
        Logger.log "Trying server #{server}:#{port}", origin: @origin, verbosity: 3

        # Initialize the tcp_server variable
        tcp_server = nil

        # Attempt to deliver the message
        begin
          Timeout.timeout(@@timeout) do # Set the timeout to @@timeout
            tcp_server = TCPSocket.new(server, port) # Initialize a TCP socket to the server
          end
        rescue Errno::ECONNREFUSED # If the connection is refused
          # Log the error and return
          Logger.log "Connection to #{server}:#{port} refused", origin: @origin, verbosity: 3, type: :warn
          return false
        rescue Timeout::Error # If the connection times out
          # Log the error and return
          Logger.log "#{server}:#{port} timed out in #{@@timeout} seconds", origin: @origin, verbosity: 3, type: :warn
          return false
        end

        # Create an SMTPServerContext for the server
        Logger.log "Creating context for server", origin: @origin, verbosity: 3 # Log it
        context = SMTP::SMTPServerContext.new(tcp_server) # Creare the context
        context.recipient_addr = @recipient_addr # Set the recipient addr
        context.sender_addr = @sender_addr # Set the sener addr
        context.data = @message # Set the data

        # Create a handler and handle the client
        Logger.log "Handling server", origin: @origin, verbosity: 3
        handler = Handlers::SMTPServerHandler.new(context)
        return handler.handle_client(context)
      end
    end
  end
end

# SMPT Transport authorization by rules

module SMTPServer
  module Transport
    class Authorization
      # Define the active authorization variable
      @@active_authorization = nil

      # Create a new authorization handler by file
      def initialize(authorization_file)
        @file = authorization_file # Set the filename
        @authorization = JSON.parse(File.read(@file)) # Parse the file
      end

      # Check if the context is authorized
      def authorized?(context)
        sender_address = Destination.new(context.mailfrom, get_servers: false).address # Get the sender address
        sender_user, sender_domain = sender_address.split(?@) # Split it into the sender user and domain

        sender_ip = IPAddr.new(context.ip_addr) # Get the sender IP as an IPAddr
        authenticated_as = context.authenticated_as # Get the current authentication status

        # For each recipient
        context.rcptto.each do |recipient|
          destination = Destination.new(recipient, get_servers: false) # Get the destination
          destination_address = destination.address # Get the address
          destination_user, destination_domain = destination_address.split(?@) # Split the address into the user and domain

          # For each authorization rule
          @authorization.each do |auth_rule|
            rule_type = auth_rule["rule"].to_s.downcase # Determine the rule type (allow/deny)
            auth_exempt = auth_rule["auth_exempt"] || false # Determine if the rule would exempt the client from authorization

            # Raise an error if there is a bad type given
            raise Errors::BadAuthRuleError, rule_type unless [ "allow", "deny" ].include?(rule_type)

            # Get the match and determine conditions
            match_conditions = auth_rule["match_by"]
            determine_conditions = auth_rule["determine_by"]

            # Skip this rule if the match rules don't match the client
            next unless matches?(
              match_conditions,
              destination_user: destination_user,
              destination_domain: destination_domain,
              destination_address: destination_address,
              sender_user: sender_user,
              sender_domain: sender_domain,
              sender_address: sender_address,
              sender_ip: sender_ip,
              authenticated_as: authenticated_as
            )

            # Check if the determine conditions match the client
            result = matches?(
              determine_conditions,
              destination_user: destination_user,
              destination_domain: destination_domain,
              destination_address: destination_address,
              sender_user: sender_user,
              sender_domain: sender_domain,
              sender_address: sender_address,
              sender_ip: sender_ip,
              authenticated_as: authenticated_as
            )

            # Get the final result
            result = !result if rule_type == "deny"

            # Set the authorization exempt status
            context.authorization_exempt = auth_exempt

            # Return the authorization result
            return result
          end
        end

        # Return false if nothing matches
        return false
      end

      # Set the authorization rules active
      def set_active
        @@active_authorization = self
      end

      # Get the active authorization rules
      def self.active
        @@active_authorization
      end

      # Clear the active authorization
      def self.clear_active
        @@active_authorization = nil
      end

      # Allow the file and authorization as active
      attr_accessor :file, :authorization

      private

      # Substitute special characters (%u/%d/%a) for the user, domain, or address respectively with gsub
      def substitute_specials(string, user:, domain:, address:)
        string
          .gsub("%u", user)
          .gsub("%d", domain)
          .gsub("%a", address)
      end

      # Check if an auth rule matches the given specifications
      def matches?(auth_rule, destination_user:, destination_domain:, destination_address:, sender_user:, sender_domain:, sender_address:, sender_ip:, authenticated_as:)
        allowed_sender_ips = auth_rule["from_ip"] # Get the allowed sender IP address range

        from_email_re = auth_rule["from_email"] ?  Regexp.new(auth_rule["from_email"]) : nil # Get the regex for the from email
        to_email_re = auth_rule["to_email"] ?  Regexp.new(auth_rule["to_email"]) : nil # Get the regex from the to email

        sender_matches = from_email_re ? sender_address.match?(from_email_re) : true # Check if the sender matches
        recipient_matches = to_email_re ? destination_address.match?(to_email_re) : true # Check if the recipient matches

        if auth_rule["auth"].nil?
          auth_matches = true # Auth rule matches true if no auth rule specified
        elsif auth_rule["auth"] == false
          auth_matches = authenticated_as == false # Auth rule is true if unauthenticated and the auth rule is false
        else
          # Substitute specials for the auth rule
          required_auth = substitute_specials(
            auth_rule["auth"],
            user: sender_user,
            domain: sender_domain,
            address: sender_address
          )
          # Auth matches set if required_auth matches the authenticated as user
          auth_matches = required_auth == authenticated_as
        end

        # If there is an IP rule
        if allowed_sender_ips
          # Return true if the IP is allowed in any of the range
          ip_matches = allowed_sender_ips.any? do |ip|
            IPAddr.new(ip).include?(sender_ip)
          end
        else
          # IP rule is true if there is no rule
          ip_matches = true
        end

        # Return true if all the rules match
        return sender_matches && recipient_matches && ip_matches && auth_matches
      end
      
      # Create a new ruleset and set it active
      new(Config.active["transport"]["authorization_file"]).set_active
    end
  end
end

# Transport rules

module SMTPServer
  module Transport
    class Rules
      # Active ruleset
      @@active_rules = nil

      # Create a new ruleset from a file
      def initialize(rules_file)
        @file = rules_file
        @rules = JSON.parse(File.read(@file))
      end

      # Determine the destination for an address
      def determine_destination(address)
        user, domain = address.split(?@, 2) # Get the user and domain

        # For each transport rule
        @rules.each do |rule|
          regex, destination = rule # Get the regex and destination

          # If the address matches the rule
          if address.match?(Regexp.new(regex))
            # Get the destination user of the rule with specials fixed
            dest_user = substitute_specials(
              destination[0],
              user: user,
              domain: domain,
              address: address
            )

            # If there is a server specified, set that to the delivery server
            if destination[1]
              dest_server = {server_addrs: destination[1]}
            else # if not, no destination server
              dest_server = nil
            end

            # Return the destination user and server
            return [ dest_user, dest_server ]
          end
        end

        # If none match, return the address and mail domain
        return [ address, {mail_domain: domain} ]
      end

      # Set the rules active
      def set_active
        @@active_rules = self
      end

      # Get the active rules
      def self.active
        @@active_rules
      end

      # Clear the active rules
      def self.clear_active
        @@active_rules = {}
      end

      # Create new rules from the set rules file
      new(Config.active["transport"]["rules_file"]).set_active

      # Allow variables to be accessed
      attr_accessor :file, :rules

      private

      # Substitute specials with gsub
      def substitute_specials(string, user:, domain:, address:)
        string
          .gsub("%u", user)
          .gsub("%d", domain)
          .gsub("%a", address)
      end
    end

module SMTPServer
  module Transport
    class Destination

      # Create a new destination
      def initialize(address, get_servers: true)
        @address = fix_address(address) # Fix the address
        @addr_user, @addr_domain = @address.split(?@) # Set the address user and domain with split()
        @destination = Rules.active.determine_destination(@address) # Get the destination with rules
        @destination_user = @destination[0] # get the destination user from the rules

        # If there is a destination server
        if @destination[1]
          @destination_servers = get_servers ? get_destination_servers(@destination[1]) : [] # Get the destination servers UNLESS get_servers was set false
        else
          # If no destination server, delivery is local
          @local = true
        end

        # If local, remove dots and + signs
        if @local
          @destination_user = @destination_user.gsub(?., "").split(?+)[0]
        end
      end

      # Format the address in <> signs
      def formatted_address
        "<#{@address}>"
      end

      # Allow variables to be read
      attr_reader :address, :destination, :destination_user, :destination_servers, :local, :addr_user, :addr_domain

      private
      
      # Get the destinatino servers
      def get_destination_servers(destination)
        dest_servers = []

        # If the server_addrs aren't empty, set dest_servers to that
        if !(destination[:server_addrs].to_a.empty?)
          dest_servers = destination[:server_addrs]
        # If there is a mail domain, get the MX records and set it to that
        elsif destination[:mail_domain]
          dest_servers = get_mx_records(destination[:mail_domain])
        end

        return dest_servers
      end

      # Get the MX records for a domain
      def get_mx_records(domain)
        # Return the IP if domain is an IP in brackets
        if domain.match?(/\[.*\]/)
          return [domain[1..-2]]
        end

        begin
          # Try using resolv to get the records
          mx_records = Resolv::DNS.open do |dns|
            dns.getresources(domain, Resolv::DNS::Resource::IN::MX)
          end
        rescue
          # If that fails set it blank
          mx_records = []
        end

        # Extract the preference and exchange from the records, sort by priority, and get just the domains
        return mx_records.map{|x| [x.preference, x.exchange.to_s]}.sort_by(&:first).map(&:last)
      end

      # Fix an address to user@domain.com format
      def fix_address(address)
        # If the address is in <user@domain.com>, set it to the inside
        if address.match?(/^\<.*\>$/)
          inner_address = address[1..-2]
        # If the address is in asd <user@domain.com>, set it to just the address
        elsif address.split(?<)[-1].match?(/^.*\>$/)
          inner_address = address.split(?<)[-1][0..-2]
        # Do nothing if else
        else
          inner_address = address
        end

        # If there is no domain, add 0.0.0.0 as a placeholder
        if address.split(?@).length == 1
          return "#{inner_address}@0.0.0.0"
        # If not return the address
        else
          return inner_address
        end
      end
    end

# SMTP Command class

module SMTPServer
  module SMTP
    class Command
      # Define all valid SMTP commands and their arguments
      VALID_SMTP_COMMANDS = [
        [ "HELO", String ],
        [ "MAIL", "FROM:", String ],
        [ "RCPT", "TO:", String ],
        [ "DATA" ],
        [ "QUIT" ],
        [ "RSET" ],
        [ "VRFY", String ],
        [ "EXPN", String ],
        [ "NOOP" ],
      ]

      # Define all valid ESMTP commands and their arguments
      VALID_ESMTP_COMMANDS = [
        [ "EHLO", String ],
        [ "STARTTLS" ],
        [ "AUTH", String ],
      ]

      # Array of all calid commands (calculated later)
      @@all_valid_commands = nil

      # Create a command with the command and its arguments as input
      def initialize(command, values = [])
        @command = command
        @values = values

        # Split the command into an array unless it's already an array
        @command = @command.split(" ") unless @command.is_a?(Array)
        
        # Store the value(s) as an array unless they're already an array
        @values = [ @values ] unless @values.is_a?(Array)

        # Upcase the command
        @command.map!(&:upcase)

        # Parse the command -- this is used soley so that an error
        # is raised if it is invalid
        Command.parse_command(to_s)
      end

      # Convert the command to a string
      # The command is space-joined, and so are the values if present
      def to_s
        "#{@command.join(" ")}#{" " unless @values.empty?}#{@values.join(" ")}"
      end

      # Parse a command from a string
      def self.parse(full_command)
        # Get the parsed command and the template from the parse_command() method
        parsed_command, command_template = parse_command(full_command)

        # Get the command and its arguments from the dissect_array() method -- given
        # the array and the template from parse_command()
        command, values = dissect_array(parsed_command, command_template)

        new(command, values)
      end

      # Calculate or get all valid commands
      def self.all_valid_commands
        unless @@all_valid_commands # Run if we have not already calculated which commands are valid
          @@all_valid_commands = VALID_SMTP_COMMANDS # SMTP commands are always valid
          @@all_valid_commands += VALID_ESMTP_COMMANDS if Config.active["esmtp_enable"] # ESMTP commands
                                                                                        # valid if enabled

          @@all_valid_commands = @@all_valid_commands.filter do |command| # Get all commands that are not explicitly disabled
            !Config.active["disable_commands"].include?(command[0])
          end
        end

        # Return the calculated @@all_valid_commands
        @@all_valid_commands
      end

      # Command and values are accessible
      attr_accessor :command, :values

      private

      # Split a command to an array by its template
      def self.split_to_array(command, command_template)
        command = command.split(" ") # Split the command by spaces

        # If the template has arguments, the command has arguments given, the command template has two elements for the command, the second ending with `:`
        # , and the second element of the command does NOT end with `:` -- used for MAIL FROM: and RCPT TO: commands where there is no space left after the
        # colon
        if command_template.length >= 2 && command.length >= 2 && command_template[1].is_a?(String) && command_template[1][-1] == ?: && command[1][-1] != ?:
          command_end, argument = command.delete_at(1).split(?:) # Get the 2nd half of the command, and the start of the argument from the command
          command.insert(1, "#{command_end}:") # Re-add the command end with a colon in position 1
          command.insert(2, argument) # Re-add the argument in position 2
        end

        # Return the command
        return command
      end

      # Get the command and arguments separate from an array and template
      def self.dissect_array(command_array, template_array)
        args_start = template_array.index(String) # Get the index in the template where args start
        return [ command_array ] unless args_start # Return just the command if there are no arguments

        command_strings_end = args_start - 1 # Command strings end right before the arguments start

        # Return the command and args as positions 0 to command strings end and args start to the end respectively
        return [
          command_array[0..command_strings_end],
          command_array[args_start..-1]
        ]
      end

      # Parse a command string, returning the command as an array, and its template
      def self.parse_command(command)
        # Test for all valid commands
        Command.all_valid_commands.each do |command_template|
          # Use the command_matches_array?() method to see if it matches or not
          case command_matches_array?(command, command_template)
          # When it matches
          when true
            # Return the command split, and the template
            return [
              split_to_array(command, command_template),
              command_template
            ]
          # When it matches but is incomplete
          when :incomplete
            # Raise an error
            raise Errors::IncompleteCommandError, [command, command_template]
            # When it doesn't match
          when false
            # Skip
            next
          end
        end

        # Raise an error if it doesn't match anything
        raise Errors::InvalidCommandError, command
      end

      # Check if a command string matches a template
      def self.command_matches_array?(command, array)
        command = split_to_array(command, array) # Split the command by the template

        # Go through each element of the template
        array.each_with_index do |element, index|
          value = command[index] # Get the matching value of the command

          # If the element is a string, indicating part of the command
          if element.class == String
            # Return faluse unless the command matches this aprt
            return false unless value.to_s.upcase.gsub(" ", "") == element
          else
            # Return incomplete unless the command's element's class matches
            # the class given in the template
            if element != value.class
              return :incomplete
            end
          end
        end

        # Return true if it doesn't fail above
        return true
      end
    end
  end
end

# SMTP Response

module SMTPServer
  module SMTP
    class Response
      # Regex for a valid response code
      VALID_CODE_REGEX = /^[1-5][0-5][0-9]$/

      # All status numbers
      @@statuses = {
        information: 1,
        positive_completed: 2,
        positive_intermediate: 3,
        negative_temporary: 4,
        negative_permanent: 5
      }

      # All category numbers
      @@categories = {
        syntax: 0,
        information: 1,
        connections: 2,
        authentication: 3,
        unspecified: 4,
        mail_system: 5
      }

      # Create a response
      def initialize(status: nil, category: nil, detail: 0, code: nil, message: nil)
        # If we are given a status, category, and detail
        if status && category && detail
          # Replace the status and category with their numbers if we have symbols
          status = @@statuses[status] if status.is_a?(Symbol)
          category = @@categories[category] if category.is_a?(Symbol)

          # Raise errors if they are invalid
          raise Errors::BadCodeError, [:status, status] unless (1..5).include?(status)
          raise Errors::BadCodeError, [:category, category] unless (0..5).include?(category)
          raise Errors::BadCodeError, [:detail, detail] unless (0..9).include?(detail)

          # Set the 3 instance vars to the 3 numbers
          @status, @category, @detail = [status, category, detail]
        # If we're only given a code
        elsif code
          # Raise an error if it doesn't match the regex
          raise Errors::BadCodeError, [:fullcode, code] unless code.to_s.match?(VALID_CODE_REGEX)

          # Set the instance vars
          @status, @category, @detail = code.to_s.split("").map(&:to_i)
        # If neither are given
        else
          # Find out what exactly is missing
          missing_codes = []
          missing_codes << :status unless status
          missing_codes << :category unless category
          missing_codes << :detail unless detail

          # Raise an error
          raise Errors::BadCodeError, [:missingelements, missing_codes]
        end

        # Set the message
        @message = message
      end

      # Get the code as a string
      def code
        "#{@status}#{@category}#{@detail}"
      end

      def to_s
        to_a.join("\r\n")
      end

      def to_a
        if @message.is_a?(Array)
          response = []

          @message.each_with_index do |line, index|
            if index != 0 && index == message.length - 1
              response << "#{code} #{line}"
            else
              response << "#{code}-#{line}"
            end
          end
        else
          message = @message ? " #{@message}" : nil
          response = [ "#{code}#{message}" ]
        end

        return response
      end

      def self.parse(response)
        response = response.split(/\r?\n/) if response.is_a?(String)

        if is_multiline_incomplete?(response[0]) && is_multiline_incomplete?(response[-1])
          return :incomplete
        end

        code = response[0].split(/[\-\s]/, 2)[0]
        message = response.map{ |rline| rline.split(/[\-\s]/, 2)[-1] }

        message = message[0] if message.length == 1

        new(
          code: code,
          message: message
        )
      end

      attr_accessor :status, :category, :detail, :message

      private
      
      def self.is_multiline_incomplete?(line)
        line[3] == ?-
      end
    end
  end
end

# SMTP Queue Worker

module SMTPServer
  module Queue
    class QueueWorker
      # Define all workers, and all running workers
      @@all_workers = []
      @@running_workers = []

      # Create a queue worker with a given mod and eq
      # mod and eq are used to divvy up queue work.
      # All queue workers only attempt messages where
      # MESSAGE ID % mod == eq.
      def initialize(mod:, eq:)
        # Define variables
        @mod = mod
        @eq = eq

        # Queue workers status info
        @running = false
        @dead = false
        @pid = nil

        # Logger origin
        @origin = "Worker #{eq}"

        # Add the worker to the list
        @@all_workers << self
      end

      # Start the worker
      def start
        # Don't attempt if dead
        return false if @dead

        # Don't attempt if already running
        return true if @running

        # Set status to running
        @running = true

        # Add self to running workers
        @@running_workers << self

        # Start the process
        @pid = fork do
          # Trap the INT signal for graceful shutdown
          Signal.trap("INT", "IGNORE")

          # Try to connect to the DB
          begin
            Database.connect
            Logger.log "Connected to database", origin: @origin, verbosity: 1
          # Quit if we can't
          rescue => e
            Logger.log "Failed to connect to database", origin: @origin, verbosity: 1, type: :error
            raise e
          end

          # Log queue handling status
          Logger.log "Handling queued jobs (#{@eq}:#{@mod})", origin: @origin, verbosity: 1

          # Create a queue handler
          handler = QueueHandler.new(mod: @mod, eq: @eq)

          # Run it
          handler.run
        end

        # Return the PID
        return @pid
      end

      # Restart the worker
      def restart
        # Stop
        stop
        # Wait the designated restart_delay time
        sleep(Config.active["queue"]["workers"]["restart_delay"])
        # Start again
        start
      end

      # Stop self with a signal (default TERM)
      def stop(killcode: "TERM")
        # Kill the PID
        Process.kill(killcode, @pid)

        # Set running false
        @running = false

        # Remove from running workers
        @@running_workers.delete(self)

        # Log
        Logger.log "Stopped worker", origin: @origin, verbosity: 1
      end

      # Kill worker
      def kill
        # Stop
        stop
        # Set dead
        @dead = true
        # Remove from all workers list
        @@all_workers.delete(self)

        # log
        Logger.log "Killed worker", origin: @origin, verbosity: 1
      end

      # Functions for reading variables
      def self.all_workers
        @@all_workers
      end

      def self.running_workers
        @@running_workers
      end

      attr_reader :mod, :eq, :running, :dead, :pid

module SMTPServer
  module Queue
    class QueuedMessage
      # Define some settings
      # Queued message storage directory
      queue_dir = Config.active["queue"]["queued_mail_dir"]
      # Create it if it doesn't exist
      Dir.mkdir(queue_dir) unless File.exist?(queue_dir)
      # Default amount of times to retry a message
      @@default_retries = Config.active["transport"]["max_retries"]

      # Create the message
      def initialize(mail_from:, rcpt_to:, message:, retries: @@default_retries, try_at: nil, error_response: false)
        # Define parameters
        @mail_from = mail_from
        @rcpt_to = rcpt_to
        @message = message
        @message_id = nil # This will be created later by the DB
        @queued = false # To avoid double-queueing
        @error_response = error_response # Are we an error response?
        @retries = retries # Amount of retries
        @try_at = try_at ? try_at : Time.now.to_i # When to try at
      end

      # Queue the message
      def queue
        # Quit if DB is inactive
        return false unless Database.active

        # Don't run if already queued
        unless @queued
          # Get a file path and message UID
          @file_path, @message_uid = get_path_and_id

          # Write the file
          File.write(@file_path, @message)

          # Create a DB entry
          Database.active.exec_sql *build_sql(
            mail_from: @mail_from,
            message_uid: @message_uid,
            rcpt_to: @rcpt_to,
            message: @message,
            file_path: @file_path,
            is_error_response: @error_response ? 1 : 0,
            retries: @retries,
            try_at: @try_at
          )

          # We are queued now
          @queued = true
        end

        # Return path and UID
        return [ @file_path, @message_uid ]
      end

      # Find queued messages where MESSAGE ID % mod = eq
      # This is used by the queue workers
      def self.find_by_mod(mod: 1, eq: 0)
        return nil unless Database.active # Don't try if inactive

        Database.active.exec_sql(
          "SELECT * FROM queued_messages WHERE message_id % ? = ?",
          [
            mod,
            eq
          ]
        )
      end

      # Get a message by Message ID
      def self.find_by_mid(mid)
        return nil unless Database.active # Don't try if inactive

        Database.active.exec_sql(
          "SELECT * FROM queued_messages WHERE message_id = ?",
          mid
        )
      end

      # Get a message by Unique ID
      def self.find_by_uid(uid)
        return nil unless Database.active # Don't try if inactive

        Database.active.exec_sql(
          "SELECT * FROM queued_messages WHERE message_uid = ?",
          uid
        )
      end

      # Unqueue a message by UID
      def self.unqueue_uid(uid)
        return nil unless Database.active # Don't try if inactive
        # Get the message
        messages = find_by_uid(uid)
        # Quit if it doesn't exist
        return if messages.empty?

        # Delete the file if configured to delete on unqueing a message
        if Config.active["queue"]["remove_on_unqueue"]
          path = messages[0][6]
          File.delete(path) if File.exist?(path)
        end

        # Delete from the DB
        Database.active.exec_sql(
          "DELETE FROM queued_messages WHERE message_uid = ?",
          uid
        )
      end

      # Attribute readers for vars
      attr_reader :mail_from, :rcpt_to, :message, :queued, :message_id, :file_path, :message_uid

      private

      # Build an SQL statement to make a message
      # Returns an array that can be passed to the DB adapter
      def build_sql(message_uid:, is_error_response: 0, mail_from:, rcpt_to:, message:, file_path:, retries:, try_at:)
        [
          "INSERT INTO queued_messages (message_uid, is_error_response, created_at, mail_from, rcpt_to, file_path, retries, try_at) VALUES (?, ?, ?, ?, ?, ?, ?, ?)",
          [
            message_uid,
            is_error_response,
            Time.now.to_i, 
            mail_from, 
            rcpt_to, 
            file_path,
            retries,
            try_at,
          ]
        ]
      end

      # Get a file path and ID
      def get_path_and_id
        # Repeat it
        loop do
          message_uid = rand(1000000000000..9999999999999) # Create an ID
          path = Config.active["queue"]["queued_mail_dir"] + "/#{message_uid}.eml" # Make the path
          return [ path, message_uid ] unless File.exist?(path) # Return if that number is available, otherwise try again
        end
      end
    end

# SMTP Queue Handler
# This is the code that actually tries
# to deliver the message

module SMTPServer
  module Queue
    class QueueHandler
      # Define the delivery timeout and retry interval
      @@delivery_timeout = Config.active["transport"]["delivery_timeout"]
      @@retry_interval = Config.active["transport"]["retry_interval"]

      # Create a queue handler with mod and eq (explained in queue worker)
      def initialize(mod:, eq:)
        @mod = mod
        @eq = eq

        # Logger origin
        @origin = "Worker #{eq}"
      end

      # Run the handler
      def run
        # Loop
        while true
          queued_messages = QueuedMessage.find_by_mod(mod: @mod, eq: @eq) # Get all queued messages for this handler
          queued_messages.each do |message| # iterate over each queued message
            mid, uid, is_error_response, created_at, mail_from, rcpt_to, file_path, retries, try_at = message # Get the message attributes
            next if try_at > Time.now.to_i # Skip if we aren't at the delivery try time yet

            # Set the origin to include the message
            origin = "Worker #{@eq}: #{uid}"

            # Log delivery attempt
            Logger.log "Attempting to deliver queued message to `#{rcpt_to}`", origin: origin, verbosity: 2

            # Get the destination from the rcpt_to
            destination = Transport::Destination.new(rcpt_to)

            # Get the message data from the file
            message_data = File.read(file_path)

            # If local destination
            if destination.local
              # Log
              Logger.log "Destination is local, using local delivery agent", origin: origin, verbosity: 3

              # Make a local delivery agent
              agent = Transport::LocalDeliveryAgent.new(
                user: destination.destination_user,
                message: message_data
              )
            # If remote destination
            else
              # Log
              Logger.log "Destination is remote, using remote delivery agent", origin: origin, verbosity: 3

              # Make a remote delivery agent with the message, destination, sender, and origin
              agent = Transport::RemoteDeliveryAgent.new(
                message: message_data,
                destination: destination,
                sender: mail_from,
                origin: origin
              )
            end

            # Attempt delivery
            begin
              Timeout.timeout(@@delivery_timeout) do # Timeout after @@deliver_timeout seconds
                agent.attempt_delivery # Attempt
                # Log success
                Logger.log "Message delivered successfully to #{"mailbox " if destination.local}`#{destination.destination_user}`", origin: origin, verbosity: 3
              end
            # Catch an error
            rescue => e
              # If there are no retries left
              if retries <= 0
                # Make an error email
                generator = Email::ErrorEmailGenerator.new(
                  e,
                  origin: origin,
                  mail_from: mail_from,
                  rcpt_to: rcpt_to,
                  is_error_response: is_error_response
                )
                # Queue the error email
                generator.queue_email
              # If we do have retries
              else
                # Log the error
                Logger.log "Error delivering email: `#{e}`, trying #{retries} more time#{?s unless retries == 1}", origin: origin, verbosity: 3, type: :warn

                # Queue a retry message
                retry_message = QueuedMessage.new(
                  mail_from: mail_from,
                  rcpt_to: rcpt_to,
                  message: message_data,
                  retries: retries-1, # Remove one retry
                  try_at: Time.now.to_i + @@retry_interval # Wait to attempt
                )

                # Log the queued UID
                quid = retry_message.queue[1]
                Logger.log "Queued retry message as #{quid}", origin: origin, verbosity: 3
              end
            end

            # Unqueue the message and log
            QueuedMessage.unqueue_uid(uid)
            Logger.log "Removed message #{uid} from queue", origin: origin, verbosity: 3
          end
        end
      end
    end

    # Attr readers
    attr_reader :mod, :eq
  end
end

module SMTPServer
  module MessageAuthorization

      # Authorize SPF with the context, and config settings
      def self.authorize_spf(context, config)
        # Log
        Logger.log "Attempting SPF authorization", origin: context.logger_origin, verbosity: 5

        # Create an SPF server
        spf_server = SPF::Server.new

        # Attempt authenticating
        begin
          # Create an SPF request

          result = spf_server.process(request)

          # Result code is from the server
          result_code = result.code.to_s

          # If there is an error, resort to the specified code when something goes wrong
          result_code = config["on_spf_fail"]

        Logger.log "SPF result: #{result_code}", origin: context.logger_origin, verbosity: 5

        # Add the result code to the context additional authorization data
        context.additional_authorization_data[:spf_result] = result_code

        # Return true/false if the ok results config allows this code
        return config["ok_results"].include?(result_code)
      end

# Prepended to a message when we can sign with DKIM

module SMTPServer
  module MessageAuthorization
    class DKIMSignatureHeader
      # DKIM maps from config
      @@dkim_maps = JSON.parse(
        File.read(
          Config.active["dkim_maps"]
        )
      )

      # Create a new header
      def initialize(context)
        # Email domain from destination
        @email_domain = Transport::Destination.new(context.mailfrom, get_servers: false).addr_domain

        # Get the DKIM map for this domain
        map = @@dkim_maps[@email_domain]

        # If the map is present
        if map
          # Log the attempt
          Logger.log "Attempting to sign with DKIM", origin: context.logger_origin, verbosity: 5

          # Encode the message with the mail gem
          @message_encoded = Mail.read_from_string(context.data).encoded

          # Get the DKIM key
          @key = SSL::Certificate[map["keypair"]].key
          
          # Get the domain from the map
          @domain = map["domain"]

          # Ensure selector is an array
          map["selector"] = [ map["selector"] ] if map["selector"].is_a?(String)

          # Choose a random selector from the array
          @selector = map["selector"].length == 1 ? map["selector"][0] : map["selector"][rand(0...map["selector"].length)]

          # Begin attempt
          begin
            # Create a Dkim::SignedMail with the message, domain, selector, and key
            @signature_header = Dkim::SignedMail.new(
              @message_encoded,
              domain: @domain,
              selector: @selector,
              private_key: @key
            )
              .dkim_header
              .value # Get the value of the header

            # Log
            Logger.log "Message signed successfully", origin: context.logger_origin, verbosity: 5
          rescue => e
            # If there is an error, log it and set the header nil
            Logger.log "Error signing message: #{e}", origin: context.logger_origin, verbosity: 5, type: :warn
            @signature_header = nil
          end
        else
          # If no map, log and continue
          Logger.log "Domain `#{@email_domain}` has no DKIM settings", origin: context.logger_origin, verbosity: 5, type: :warn
        end
      end

      # Return the signature header as a string
      def to_s
        @signature_header
      end
    end
  end

# SMTP plain authentication handler

module SMTPServer
  module Authentication
    # Define the plain handler method
    # Take the context and encoded credentials
    def self.method_plain_handler(context, encoded_credentials)
      # Log the attempt
      Logger.log "Trying auth PLAIN", origin: context.logger_origin, verbosity: 5

      # If there are no encoded credentials, we must request them
      unless encoded_credentials
        # 334 request
        username_request = SMTP::Response.new(
          status: :positive_intermediate,
          category: :authentication,
          detail: 4
        )
        context.send_response(username_request)

        # Read the credentials
        encoded_credentials = context.read[0]
      else
        # If we have encoded credentials, use those
        encoded_credentials = encoded_credentials[0]
      end

      # Decode them with base64, and split by the null character into username and password
      # _ is used as a placeholder because there is a \0 at the start as well we don't need.
      _, username, password = Base64.decode64(encoded_credentials).split("\0")

      # Log the username
      Logger.log "Client credentials received: #{username}:***", origin: context.logger_origin, verbosity: 5

      # Try authenticating with the Active handler
      if Active.authenticate(username, password)
        # If successful, respond 235.
        response = SMTP::Response.new(
          status: :positive_completed,
          category: :authentication,
          detail: 5,
          message: "2.7.0 Authentication Successful"
        )

        # Set the authenticated as to the username
        context.authenticated_as = username

        # Log
        Logger.log "Authenticated successfully", origin: context.logger_origin, verbosity: 5
      else
        # If unsuccessful, respond 535.
        response = SMTP::Response.new(
          status: :negative_permanent,
          category: :authentication,
          detail: 5,
          message: "5.7.8 Authentication Failed"
        )

        # Log the failure
        Logger.log "Authentication failed", origin: context.logger_origin, verbosity: 5, type: :warn
      end

      # Send the response
      context.send_response(response)
    end
  end
end

        unless @context.banner_sent
          @context.send_banner 
          Logger.log "Sending banner to client", origin: @context.logger_origin, verbosity: 4
        end

        until @context.closed
          raw_command = @context.read[0]
          begin
            command = SMTP::Command.parse(raw_command)
          rescue SMTPServer::Errors::InvalidCommandError => e
            Logger.log "Invalid command from client: `#{e.command}`", type: :warn, origin: @context.logger_origin, verbosity: 4
            response = SMTP::Response.new(
              status: :negative_permanent,
              category: :syntax,
              detail: 2,
              message: "5.5.2 command not recognized"
            )
            @context.send_response(response)
            next
          rescue SMTPServer::Errors::IncompleteCommandError => e
            Logger.log "Incomplete command from client: `#{e.original_command}`", type: :warn, origin: @context.logger_origin, verbosity: 4
            response = SMTP::Response.new(
              status: :negative_permanent,
              category: :syntax,
              detail: 1,
              message: "5.5.4 Syntax: #{e.template_command.map{|x| x == String ? "<argument>" : x}.join(" ")}"
            )
            @context.send_response(response)
            next
          end

          case command.command

          # ESMTP
          when [ "EHLO" ]
            SMTPCommandHandlers.ehlo(@context, command.values)
          when [ "STARTTLS" ]
            SMTPCommandHandlers.starttls(@context)
          when [ "AUTH" ]
            SMTPCommandHandlers.auth(@context, command.values)

          # SMTP
          when [ "HELO" ]
            SMTPCommandHandlers.helo(@context, command.values)
          when [ "MAIL", "FROM:" ]
            SMTPCommandHandlers.mailfrom(@context, command.values)
          when [ "RCPT", "TO:" ]
            SMTPCommandHandlers.rcptto(@context, command.values)
          when [ "DATA" ]
            SMTPCommandHandlers.data(@context)
          when [ "QUIT" ]
            SMTPCommandHandlers.quit(@context)
          when [ "RSET" ]
            SMTPCommandHandlers.rset(@context)
          when [ "VRFY" ]
            SMTPCommandHandlers.vrfy(@context, command.values)
          when [ "EXPN" ]
            SMTPCommandHandlers.expn(@context, command.values)
          when [ "NOOP" ]
            SMTPCommandHandlers.noop(@context)
          end
        end
      end
    end
  end
end

module SMTPServer
  module Handlers
    module SMTPCommandHandlers
      def self.data(context)
        unless context.data == :ready
          Logger.log "Received unexpected DATA command", origin: context.logger_origin, verbosity: 5, type: :warn

          message = SMTP::Response.new(
            status: :negative_permanent,
            category: :syntax,
            detail: 3,
            message: "5.5.1 Error: MAIL FROM: required"
          )
          context.send_response(message)
          return
        end

        Logger.log "Received DATA command, waiting for message", origin: context.logger_origin, verbosity: 5

        message = SMTP::Response.new(
          status: :positive_intermediate,
          category: :mail_system,
          detail: 4,
          message: "End data with <CRLF>.<CRLF>"
        )
        context.send_response(message)

        data = context.read(read_until: ".").map{ |l| l[0] == ?. ? l[1..-1] : l }.join("\r\n")

        if data.length > Config.active["max_size"]
          message = SMTP::Response.new(
            status: :negative_permanent,
            category: :mail_system,
            detail: 2,
            message: "5.3.4 Message exceeds max size"
          )
          context.send_response(message)

          Logger.log "Message exceeds max size", origin: context.logger_origin, verbosity: 5, type: :warn
          return
        end

        context.data = data

        unless context.authorization_exempt
          Config.active["postdata_authorization_adapters"].each do |adapter, config|
            auth_const, auth_method = adapter.split(?#)

              unless Object.const_get(auth_const).method(auth_method).call(context, config)
                message = SMTP::Response.new(
                  status: :negative_permanent,
                  category: :authentication,
                  detail: 5,
                  message: "5.7.8 Error: authorization failed"
                )
                context.send_response(message)
                context.reset

                Logger.log "Authorization failed; rejecting message", origin: context.logger_origin, verbosity: 5, type: :warn
                return
              end
          end
        else
          Logger.log "Authorization exempt; skipping authorization adapters", origin: context.logger_origin, verbosity: 5
        end

        queue_ids = []

        preparer = Email::EmailPreparer.new(context)
        preparer.add_all_headers

        i = 0
        while i < context.rcptto.length
          rcpt_to = context.rcptto[i]
          i += 1

          fixed_address = Transport::Destination.new(rcpt_to, get_servers: false).address

          mail_list = MailLists::MailList.find_by_name(fixed_address)

          if mail_list
            context.rcptto.delete(rcpt_to)
            context.rcptto += mail_list.expand
            i -= 1
            next
          end

          message = Queue::QueuedMessage.new(
            mail_from: Transport::Destination.new(context.mailfrom, get_servers: false).address,
            rcpt_to: Transport::Destination.new(rcpt_to, get_servers: false).address,
            message: preparer.to_s
          )

          queue_ids << message.queue[1]
        end

        message = SMTP::Response.new(
          status: :positive_completed,
          category: :mail_system,
          message: Config.active["queue"]["return_queue_ids"] ? "2.0.0 Message queued as #{queue_ids.join(?,)}" : "2.0.0 Message queued"
        )
        context.send_response(message)

        context.reset

        Logger.log "Queued message as #{queue_ids.join(?,)}", origin: context.logger_origin, verbosity: 5
      end
    end
  end

      def initialize(context)
        @context = context
      end

      def handle_client(context)
        server_banner = context.read_response

        Logger.log "Server ready: #{server_banner.message}", origin: context.logger_origin, verbosity: 4

        while true
          ready_for = context.ready_for
          case ready_for
          when :ehlo
            SMTPServerCommandHandlers.ehlo(context)
          when :helo
            SMTPServerCommandHandlers.helo(context)
          when :re_ehlo
            SMTPServerCommandHandlers.ehlo(context, attempt_starttls: false)

          when :mailfrom
            SMTPServerCommandHandlers.mailfrom(context)
          when :rcptto
            SMTPServerCommandHandlers.rcptto(context)
          when :data
            SMTPServerCommandHandlers.data(context)
          when :quit_positive
            SMTPServerCommandHandlers.quit(context)
            return true
          when :quit_negative
            SMTPServerCommandHandlers.quit(context, negative: true)
            return false
          end
        end
      end
    end

module SMTPServer
  module Servers
    class MailServer
      @@all_servers = []
      @@running_servers = []

      def initialize(host:, port:, encryption:, certificate:)
        @host = host
        @port = port
        @running = false
        @dead = false
        @pid = nil
        @encryption = encryption
        @certificate = certificate

        obj_id = self.object_id
        @origin = "Server #{obj_id}"

        @@all_servers << self
      end

      def start
        return false if @dead
        return true if @running

        @running = true
        @@running_servers << self

        @pid = fork do
          Signal.trap("INT", "IGNORE")

          begin
            Database.connect
            Logger.log "Successfully connected to database", origin: @origin, verbosity: 1
          rescue => e
            Logger.log "Error connecting to database", type: :error, origin: @origin
            raise e
          end

          tcp_server = TCPServer.new(@host, @port)
          
          if @encryption == :implicit
            context = @certificate.context
            server = OpenSSL::SSL::SSLServer.new(tcp_server, context)
          else
            server = tcp_server
          end

          Logger.log "Listening on #{@host}:#{@port}, encryption: #{@encryption}", origin: @origin, verbosity: 1

          while @running
            begin
              Thread.start(server.accept) do |client|
                client_ip = client.peeraddr[3]

                Logger.log "New connection from #{client_ip}", origin: @origin, verbosity: 2

                context = SMTP::SMTPClientContext.new(client)
                context.starttls_support = true if @encryption == :starttls
                context.starttls_certificate = @certificate&.context

                Logger.log "Creating SMTP client context for #{client_ip}", origin: @origin, verbosity: 3

                Logger.log "Handling client #{client_ip}", origin: @origin, verbosity: 3
                handler = Handlers::GenericClientHandler.new(context)
                handler.handle_client
              end
            rescue OpenSSL::SSL::SSLError
              Logger.log "SSL error for client", origin: @origin, verbosity: 2, type: :warn
            end
          end
        end

        return @pid
      end

      def restart
        stop
        sleep(Config.active["socket"]["restart_delay"])
        start
      end

      def stop(killcode: "TERM")
        Process.kill(killcode, @pid)
        @running = false
        @@running_servers.delete(self)

        Logger.log "Stopped server", origin: @origin, verbosity: 1
      end

      def kill
        stop
        @dead = true
        @@all_servers.delete(self)

        Logger.log "Killed server", origin: @origin, verbosity: 1
      end

      def self.all_servers
        @@all_servers
      end

      def self.running_servers
        @@running_servers
      end

      attr_reader :host, :port, :running, :dead, :pid
    end
  end
end

module SMTPServer
  module Email
    class ErrorEmailGenerator
      def initialize(error, origin:, mail_from:, rcpt_to:, is_error_response:)
        @error = error
        @origin = origin
        @mail_from = mail_from
        @rcpt_to = rcpt_to
        @is_error_response = is_error_response
      end

      def queue_email
        error = :other_internal
        error = "bad_mailbox" if @error.class == SMTPServer::Errors::NonexistentMailboxError
        error = "delivery_timeout" if @error.class == Timeout::Error
        error = "delivery_failed" if @error.class == SMTPServer::Errors::ServerRejectionError

        if error == :other_internal
          Logger.log "Unexpected error when delivering email: #{@error}", origin: @origin, verbosity: 3, type: :warn
        else
          Logger.log "Error delivering email: `#{@error}`", origin: @origin, verbosity: 3, type: :warn

          error_email = Email::ErrorEmail.new(
            original_from: @mail_from,
            original_to: @rcpt_to,
            email_name: error
          )

          err_email_text = error_email.prepared_email

          if @is_error_response == 0 && err_email_text
            queued_response = Queue::QueuedMessage.new(
              mail_from: Config.active["contact_email"],
              rcpt_to: @mail_from,
              message: err_email_text,
              error_response: true
            )

            id = queued_response.queue[1]

            Logger.log "Queued error response as `#{id}`", origin: @origin, verbosity: 4
          elsif @is_error_response == 1
            Logger.log "Original message was an error response; not sending another error response", origin: @origin, verbosity: 4
          end
        end
      end
    end
  end

        @og_to = original_to

        email_text = raw_original_text
        return false unless email_text

        Mail.read_from_string(email_text).to_s
      end

    end

module SMTPServer
  module Transport
    class RemoteDeliveryAgent
      @@attempt_ports = Config.active["external_transport"]["attempt_ports"]
      @@timeout = Config.active["external_transport"]["socket_timeout"]

      def initialize(destination:, sender:,  message:, origin:)
        @message = message
        @destination = destination
        @servers = @destination.destination_servers
        @recipient_addr = @destination.destination_user
        @sender_addr = sender
        @origin = origin
      end

      def attempt_delivery
        @@attempt_ports.each do |port|
          @servers.each do |server|
            return true if deliver_to_server(server, port)
          end
        end

        raise Errors::ServerRejectionError
      end

      attr_accessor :message, :destination, :servers, :recipient_addr

      private

      def deliver_to_server(server, port)
        Logger.log "Trying server #{server}:#{port}", origin: @origin, verbosity: 3
        tcp_server = nil

        begin
          Timeout.timeout(@@timeout) do
            tcp_server = TCPSocket.new(server, port)
          end
        rescue Errno::ECONNREFUSED
          Logger.log "Connection to #{server}:#{port} refused", origin: @origin, verbosity: 3, type: :warn
          return false
        rescue Timeout::Error
          Logger.log "#{server}:#{port} timed out in #{@@timeout} seconds", origin: @origin, verbosity: 3, type: :warn
          return false
        end

        Logger.log "Creating context for server", origin: @origin, verbosity: 3
        context = SMTP::SMTPServerContext.new(tcp_server)
        context.recipient_addr = @recipient_addr
        context.sender_addr = @sender_addr
        context.data = @message

        Logger.log "Handling server", origin: @origin, verbosity: 3
        handler = Handlers::SMTPServerHandler.new(context)
        return handler.handle_client(context)
      end
    end
  end
end

module SMTPServer
  module Transport
    class Authorization
      @@active_authorization = nil

      def initialize(authorization_file)
        @file = authorization_file
        @authorization = JSON.parse(File.read(@file))
      end

      def authorized?(context)
        sender_address = Destination.new(context.mailfrom, get_servers: false).address
        sender_user, sender_domain = sender_address.split(?@)

        sender_ip = IPAddr.new(context.ip_addr)
        authenticated_as = context.authenticated_as

        context.rcptto.each do |recipient|
          destination = Destination.new(recipient, get_servers: false)

          destination_address = destination.address
          destination_user, destination_domain = destination_address.split(?@)

          @authorization.each do |auth_rule|
            rule_type = auth_rule["rule"].to_s.downcase
            auth_exempt = auth_rule["auth_exempt"] || false

            raise Errors::BadAuthRuleError, rule_type unless [ "allow", "deny" ].include?(rule_type)

            match_conditions = auth_rule["match_by"]
            determine_conditions = auth_rule["determine_by"]

            next unless matches?(
              match_conditions,
              destination_user: destination_user,
              destination_domain: destination_domain,
              destination_address: destination_address,
              sender_user: sender_user,
              sender_domain: sender_domain,
              sender_address: sender_address,
              sender_ip: sender_ip,
              authenticated_as: authenticated_as
            )

            result = matches?(
              determine_conditions,
              destination_user: destination_user,
              destination_domain: destination_domain,
              destination_address: destination_address,
              sender_user: sender_user,
              sender_domain: sender_domain,
              sender_address: sender_address,
              sender_ip: sender_ip,
              authenticated_as: authenticated_as
            )

            result = !result if rule_type == "deny"

            context.authorization_exempt = auth_exempt

            return result
          end
        end

        return false
      end

      def set_active
        @@active_authorization = self
      end

      def self.active
        @@active_authorization
      end

      def self.clear_active
        @@active_authorization = nil
      end

      attr_accessor :file, :authorization

      private

      def substitute_specials(string, user:, domain:, address:)
        string
          .gsub("%u", user)
          .gsub("%d", domain)
          .gsub("%a", address)
      end

      def matches?(auth_rule, destination_user:, destination_domain:, destination_address:, sender_user:, sender_domain:, sender_address:, sender_ip:, authenticated_as:)
        allowed_sender_ips = auth_rule["from_ip"]

        from_email_re = auth_rule["from_email"] ?  Regexp.new(auth_rule["from_email"]) : nil
        to_email_re = auth_rule["to_email"] ?  Regexp.new(auth_rule["to_email"]) : nil

        sender_matches = from_email_re ? sender_address.match?(from_email_re) : true
        recipient_matches = to_email_re ? destination_address.match?(to_email_re) : true

        if auth_rule["auth"].nil?
          auth_matches = true
        elsif auth_rule["auth"] == false
          auth_matches = authenticated_as == false
        else
          required_auth = substitute_specials(
            auth_rule["auth"],
            user: sender_user,
            domain: sender_domain,
            address: sender_address
          )
          auth_matches = required_auth == authenticated_as
        end

        if allowed_sender_ips
          ip_matches = allowed_sender_ips.any? do |ip|
            IPAddr.new(ip).include?(sender_ip)
          end
        else
          ip_matches = true
        end

        return sender_matches && recipient_matches && ip_matches && auth_matches
      end
      
      new(Config.active["transport"]["authorization_file"]).set_active
    end
  end

### ./lib/mlsmtp/transport/destination.rb```
module SMTPServer
  module Transport
    class Destination
      def initialize(address, get_servers: true)
        @address = fix_address(address)
        @addr_user, @addr_domain = @address.split(?@)
        @destination = Rules.active.determine_destination(@address)
        @destination_user = @destination[0]

        if @destination[1]
          @destination_servers = get_servers ? get_destination_servers(@destination[1]) : []
        else
          @local = true
        end

        if @local
          @destination_user = @destination_user.gsub(?., "").split(?+)[0]
        end
      end

      def formatted_address
        "<#{@address}>"
      end

      attr_reader :address, :destination, :destination_user, :destination_servers, :local, :addr_user, :addr_domain

      private
      
      def get_destination_servers(destination)
        dest_servers = []

        if !(destination[:server_addrs].to_a.empty?)
          dest_servers = destination[:server_addrs]
        elsif destination[:mail_domain]
          dest_servers = get_mx_records(destination[:mail_domain])
        end

        return dest_servers
      end

      def get_mx_records(domain)
        if domain.match?(/\[.*\]/)
          return [domain[1..-2]]
        end

        begin
          mx_records = Resolv::DNS.open do |dns|
            dns.getresources(domain, Resolv::DNS::Resource::IN::MX)
          end
        rescue
          mx_records = []
        end

        return mx_records.map{|x| [x.preference, x.exchange.to_s]}.sort_by(&:first).map(&:last)
      end

      def fix_address(address)
        if address.match?(/^\<.*\>$/)
          inner_address = address[1..-2]
        elsif address.split(?<)[-1].match?(/^.*\>$/)
          inner_address = address.split(?<)[-1][0..-2]
        else
          inner_address = address
        end

        if address.split(?@).length == 1
          return "#{inner_address}@0.0.0.0"
        else
          return inner_address
        end
      end
    end
  end

      end

      def self.parse(full_command)
        parsed_command, command_template = parse_command(full_command)

        command, values = dissect_array(parsed_command, command_template)

        new(command, values)
      end

      def self.all_valid_commands
        unless @@all_valid_commands
          @@all_valid_commands = VALID_SMTP_COMMANDS
          @@all_valid_commands += VALID_ESMTP_COMMANDS if Config.active["esmtp_enable"]

          @@all_valid_commands = @@all_valid_commands.filter do |command|
            !Config.active["disable_commands"].include?(command[0])
          end
        end

        @@all_valid_commands
      end

      attr_accessor :command, :values

      private

      def self.split_to_array(command, command_template)
        command = command.split(" ")

        if command_template.length >= 2 && command.length >= 2 && command_template[1].is_a?(String) && command_template[1][-1] == ?: && command[1][-1] != ?:
          command_end, argument = command.delete_at(1).split(?:)
          command.insert(1, "#{command_end}:")
          command.insert(2, argument)
        end

        return command
      end

      def self.dissect_array(command_array, template_array)
        args_start = template_array.index(String)
        return [ command_array ] unless args_start

        command_strings_end = args_start - 1

        return [
          command_array[0..command_strings_end],
          command_array[args_start..-1]
        ]
      end

      def self.parse_command(command)
        Command.all_valid_commands.each do |command_template|
          case command_matches_array?(command, command_template)
          when true
            return [
              split_to_array(command, command_template),
              command_template
            ]
          when :incomplete
            raise Errors::IncompleteCommandError, [command, command_template]
          when false
            next
          end
        end

        raise Errors::InvalidCommandError, command
      end

      def self.command_matches_array?(command, array)
        command = split_to_array(command, array)

        array.each_with_index do |element, index|
          value = command[index]

          if element.class == String
            return false unless value.to_s.upcase.gsub(" ", "") == element
          else
            if element != value.class
              return :incomplete
            end
          end
        end

        return true
      end
    end
  end

module SMTPServer
  module SMTP
    class Response
      VALID_CODE_REGEX = /^[1-5][0-5][0-9]$/

      @@statuses = {
        information: 1,
        positive_completed: 2,
        positive_intermediate: 3,
        negative_temporary: 4,
        negative_permanent: 5
      }

      @@categories = {
        syntax: 0,
        information: 1,
        connections: 2,
        authentication: 3,
        unspecified: 4,
        mail_system: 5
      }

      def initialize(status: nil, category: nil, detail: 0, code: nil, message: nil)
        if status && category && detail
          status = @@statuses[status] if status.is_a?(Symbol)
          category = @@categories[category] if category.is_a?(Symbol)

          raise Errors::BadCodeError, [:status, status] unless (1..5).include?(status)
          raise Errors::BadCodeError, [:category, category] unless (0..5).include?(category)
          raise Errors::BadCodeError, [:detail, detail] unless (0..9).include?(detail)

          @status, @category, @detail = [status, category, detail]
        elsif code
          raise Errors::BadCodeError, [:fullcode, code] unless code.to_s.match?(VALID_CODE_REGEX)

          @status, @category, @detail = code.to_s.split("").map(&:to_i)
        else
          missing_codes = []
          missing_codes << :status unless status
          missing_codes << :category unless category
          missing_codes << :detail unless detail

          raise Errors::BadCodeError, [:missingelements, missing_codes]
        end

        @message = message
      end

      def code
        "#{@status}#{@category}#{@detail}"
      end

      def to_s
        to_a.join("\r\n")
      end

      def to_a
        if @message.is_a?(Array)
          response = []

          @message.each_with_index do |line, index|
            if index != 0 && index == message.length - 1
              response << "#{code} #{line}"
            else
              response << "#{code}-#{line}"
            end
          end
        else
          message = @message ? " #{@message}" : nil
          response = [ "#{code}#{message}" ]
        end

        return response
      end

      def self.parse(response)
        response = response.split(/\r?\n/) if response.is_a?(String)

        if is_multiline_incomplete?(response[0]) && is_multiline_incomplete?(response[-1])
          return :incomplete
        end

        code = response[0].split(/[\-\s]/, 2)[0]
        message = response.map{ |rline| rline.split(/[\-\s]/, 2)[-1] }

        message = message[0] if message.length == 1

        new(
          code: code,
          message: message
        )
      end

      attr_accessor :status, :category, :detail, :message

      private
      
      def self.is_multiline_incomplete?(line)
        line[3] == ?-
      end
    end
  end

          handler.run
        end

        start
      end

        @running = false
        @@running_workers.delete(self)

        Logger.log "Stopped worker", origin: @origin, verbosity: 1
      end

        stop
        @dead = true
        @@all_workers.delete(self)

        Logger.log "Killed worker", origin: @origin, verbosity: 1
      end

        @@all_workers
      end

      def self.running_workers
        @@running_workers
      end

### ./lib/mlsmtp/queue/queue_handler.rb```
module SMTPServer
  module Queue
    class QueueHandler
      @@delivery_timeout = Config.active["transport"]["delivery_timeout"]
      @@retry_interval = Config.active["transport"]["retry_interval"]

      def initialize(mod:, eq:)
        @mod = mod
        @eq = eq

        @origin = "Worker #{eq}"
      end

      def run
        while true
          queued_messages = QueuedMessage.find_by_mod(mod: @mod, eq: @eq)
          queued_messages.each do |message|
            mid, uid, is_error_response, created_at, mail_from, rcpt_to, file_path, retries, try_at = message
            next if try_at > Time.now.to_i

            origin = "Worker #{@eq}: #{uid}"

            Logger.log "Attempting to deliver queued message to `#{rcpt_to}`", origin: origin, verbosity: 2

            destination = Transport::Destination.new(rcpt_to)

            message_data = File.read(file_path)

            if destination.local
              Logger.log "Destination is local, using local delivery agent", origin: origin, verbosity: 3

              agent = Transport::LocalDeliveryAgent.new(
                user: destination.destination_user,
                message: message_data
              )
            else
              Logger.log "Destination is remote, using remote delivery agent", origin: origin, verbosity: 3

              agent = Transport::RemoteDeliveryAgent.new(
                message: message_data,
                destination: destination,
                sender: mail_from,
                origin: origin
              )
            end

            begin
              Timeout.timeout(@@delivery_timeout) do
                agent.attempt_delivery
                Logger.log "Message delivered successfully to #{"mailbox " if destination.local}`#{destination.destination_user}`", origin: origin, verbosity: 3
              end
            rescue => e
              if retries <= 0
                generator = Email::ErrorEmailGenerator.new(
                  e,
                  origin: origin,
                  mail_from: mail_from,
                  rcpt_to: rcpt_to,
                  is_error_response: is_error_response
                )
                generator.queue_email
              else
                Logger.log "Error delivering email: `#{e}`, trying #{retries} more time#{?s unless retries == 1}", origin: origin, verbosity: 3, type: :warn

                retry_message = QueuedMessage.new(
                  mail_from: mail_from,
                  rcpt_to: rcpt_to,
                  message: message_data,
                  retries: retries-1,
                  try_at: Time.now.to_i + @@retry_interval
                )

                quid = retry_message.queue[1]
                Logger.log "Queued retry message as #{quid}", origin: origin, verbosity: 3
              end
            end

            QueuedMessage.unqueue_uid(uid)
            Logger.log "Removed message #{uid} from queue", origin: origin, verbosity: 3
          end
        end
      end
    end

    attr_reader :mod, :eq
  end

  module Authentication
    def self.method_login_handler(context, _)
      Logger.log "Trying auth LOGIN", origin: context.logger_origin, verbosity: 5

      username_request = SMTP::Response.new(
        status: :positive_intermediate,
        category: :authentication,
        detail: 4,
        message: "VXNlcm5hbWU6"
      )
      context.send_response(username_request)
      username = Base64.decode64(context.read[0])

      Logger.log "Client username: #{username}", origin: context.logger_origin, verbosity: 5

      password_request = SMTP::Response.new(
        status: :positive_intermediate,
        category: :authentication,
        detail: 4,
        message: "UGFzc3dvcmQ6"
      )
      context.send_response(password_request)
      password = Base64.decode64(context.read[0])

      Logger.log "Client password received", origin: context.logger_origin, verbosity: 5

      if Active.authenticate(username, password)
        response = SMTP::Response.new(
          status: :positive_completed,
          category: :authentication,
          detail: 5,
          message: "2.7.0 Authentication Successful"
        )

        context.authenticated_as = username

        Logger.log "Authenticated successfully", origin: context.logger_origin, verbosity: 5
      else
        response = SMTP::Response.new(
          status: :negative_permanent,
          category: :authentication,
          detail: 5,
          message: "5.7.8 Authentication Failed"
        )

        Logger.log "Authentication failed", origin: context.logger_origin, verbosity: 5, type: :warn
      end

      context.send_response(response)
    end
  end

module SMTPServer
  module Handlers
    class GenericClientHandler
      def initialize(context)
        @context = context
      end

      def handle_client
        unless @context.banner_sent
          @context.send_banner 
          Logger.log "Sending banner to client", origin: @context.logger_origin, verbosity: 4
        end

        until @context.closed
          raw_command = @context.read[0]
          begin
            command = SMTP::Command.parse(raw_command)
          rescue SMTPServer::Errors::InvalidCommandError => e
            Logger.log "Invalid command from client: `#{e.command}`", type: :warn, origin: @context.logger_origin, verbosity: 4
            response = SMTP::Response.new(
              status: :negative_permanent,
              category: :syntax,
              detail: 2,
              message: "5.5.2 command not recognized"
            )
            @context.send_response(response)
            next
          rescue SMTPServer::Errors::IncompleteCommandError => e
            Logger.log "Incomplete command from client: `#{e.original_command}`", type: :warn, origin: @context.logger_origin, verbosity: 4
            response = SMTP::Response.new(
              status: :negative_permanent,
              category: :syntax,
              detail: 1,
              message: "5.5.4 Syntax: #{e.template_command.map{|x| x == String ? "<argument>" : x}.join(" ")}"
            )
            @context.send_response(response)
            next
          end

          case command.command

          # ESMTP
          when [ "EHLO" ]
            SMTPCommandHandlers.ehlo(@context, command.values)
          when [ "STARTTLS" ]
            SMTPCommandHandlers.starttls(@context)
          when [ "AUTH" ]
            SMTPCommandHandlers.auth(@context, command.values)

          # SMTP
          when [ "HELO" ]
            SMTPCommandHandlers.helo(@context, command.values)
          when [ "MAIL", "FROM:" ]
            SMTPCommandHandlers.mailfrom(@context, command.values)
          when [ "RCPT", "TO:" ]
            SMTPCommandHandlers.rcptto(@context, command.values)
          when [ "DATA" ]
            SMTPCommandHandlers.data(@context)
          when [ "QUIT" ]
            SMTPCommandHandlers.quit(@context)
          when [ "RSET" ]
            SMTPCommandHandlers.rset(@context)
          when [ "VRFY" ]
            SMTPCommandHandlers.vrfy(@context, command.values)
          when [ "EXPN" ]
            SMTPCommandHandlers.expn(@context, command.values)
          when [ "NOOP" ]
            SMTPCommandHandlers.noop(@context)
          end
        end
      end
    end
  end
end

    module SMTPCommandHandlers
      def self.expn(context, args)
        list = Transport::Destination.new(args[0], get_servers: false).address

        list_members = MailLists::MailList.find_by_name(list)&.expand

        if list_members.nil? || list_members.empty?
          response = SMTP::Response.new(
            status: :negative_permanent,
            category: :mail_system,
            message: "Mailing list is empty or does not exist"
          )

          Logger.log "Requested email list `#{list}` is empty or does not exist", origin: context.logger_origin, verbosity: 5, type: :warn
        else
          response = SMTP::Response.new(
            status: :positive_completed,
            category: :mail_system,
            message: list_members.map{|m| "<#{m}>"}
          )

          Logger.log "Returned #{list_members.length} members of list #{list}", origin: context.logger_origin, verbosity: 5
        end

        context.send_response(response)
      end
    end
  end

module SMTPServer
  module Handlers
    module SMTPCommandHandlers
      def self.data(context)
        unless context.data == :ready
          Logger.log "Received unexpected DATA command", origin: context.logger_origin, verbosity: 5, type: :warn

          message = SMTP::Response.new(
            status: :negative_permanent,
            category: :syntax,
            detail: 3,
            message: "5.5.1 Error: MAIL FROM: required"
          )
          context.send_response(message)
          return
        end

        Logger.log "Received DATA command, waiting for message", origin: context.logger_origin, verbosity: 5

        message = SMTP::Response.new(
          status: :positive_intermediate,
          category: :mail_system,
          detail: 4,
          message: "End data with <CRLF>.<CRLF>"
        )
        context.send_response(message)

        data = context.read(read_until: ".").map{ |l| l[0] == ?. ? l[1..-1] : l }.join("\r\n")

        if data.length > Config.active["max_size"]
          message = SMTP::Response.new(
            status: :negative_permanent,
            category: :mail_system,
            detail: 2,
            message: "5.3.4 Message exceeds max size"
          )
          context.send_response(message)

          Logger.log "Message exceeds max size", origin: context.logger_origin, verbosity: 5, type: :warn
          return
        end

        context.data = data

        unless context.authorization_exempt
          Config.active["postdata_authorization_adapters"].each do |adapter, config|
            auth_const, auth_method = adapter.split(?#)

              unless Object.const_get(auth_const).method(auth_method).call(context, config)
                message = SMTP::Response.new(
                  status: :negative_permanent,
                  category: :authentication,
                  detail: 5,
                  message: "5.7.8 Error: authorization failed"
                )
                context.send_response(message)
                context.reset

                Logger.log "Authorization failed; rejecting message", origin: context.logger_origin, verbosity: 5, type: :warn
                return
              end
          end
        else
          Logger.log "Authorization exempt; skipping authorization adapters", origin: context.logger_origin, verbosity: 5
        end

        queue_ids = []

        preparer = Email::EmailPreparer.new(context)
        preparer.add_all_headers

        i = 0
        while i < context.rcptto.length
          rcpt_to = context.rcptto[i]
          i += 1

          fixed_address = Transport::Destination.new(rcpt_to, get_servers: false).address

          mail_list = MailLists::MailList.find_by_name(fixed_address)

          if mail_list
            context.rcptto.delete(rcpt_to)
            context.rcptto += mail_list.expand
            i -= 1
            next
          end

          message = Queue::QueuedMessage.new(
            mail_from: Transport::Destination.new(context.mailfrom, get_servers: false).address,
            rcpt_to: Transport::Destination.new(rcpt_to, get_servers: false).address,
            message: preparer.to_s
          )

          queue_ids << message.queue[1]
        end

        message = SMTP::Response.new(
          status: :positive_completed,
          category: :mail_system,
          message: Config.active["queue"]["return_queue_ids"] ? "2.0.0 Message queued as #{queue_ids.join(?,)}" : "2.0.0 Message queued"
        )
        context.send_response(message)

        context.reset

        Logger.log "Queued message as #{queue_ids.join(?,)}", origin: context.logger_origin, verbosity: 5
      end
    end
  end
end

      end

module SMTPServer
  module Handlers
    module SMTPCommandHandlers
      def self.starttls(context)
        unless context.starttls_support
          response = SMTP::Response.new(
            status: :negative_permanent,
            category: :syntax,
            detail: 2,
            message: "5.5.2 Error: command not recognized"
          )
          context.send_response(response)

          Logger.log "This context does not support STARTTLS", origin: context.logger_origin, verbosity: 5, type: :warn

          return
        end

        if context.using_starttls
          response = SMTP::Response.new(
            status: :negative_permanent,
            category: :syntax,
            detail: 3,
            message: "5.5.2 Error: already using STARTTLS"
          )
          context.send_response(response)

          Logger.log "Already using STARTTLS", origin: context.logger_origin, verbosity: 5, type: :warn

          return
        end

        response = SMTP::Response.new(
          status: :positive_completed,
          category: :connections,
          message: "2.0.0 Ready to start TLS"
        )

        context.send_response(response)

        begin
          ssl_context = context.starttls_certificate
          ssl_socket = OpenSSL::SSL::SSLSocket.new(context.tcp_client, ssl_context)
          ssl_socket.sync_close = true
          ssl_socket.accept

          context.client = ssl_socket

          context.using_starttls = true

          Logger.log "Upgraded to TLS", origin: context.logger_origin, verbosity: 5
        rescue OpenSSL::SSL::SSLError
          Logger.log "Failed upgrading to TLS", origin: context.logger_origin, verbosity: 5, type: :warn
        end
      end
    end
  end
end

module SMTPServer
  module Handlers
    class SMTPServerHandler
      def initialize(context)
        @context = context
      end

      def handle_client(context)
        server_banner = context.read_response

        Logger.log "Server ready: #{server_banner.message}", origin: context.logger_origin, verbosity: 4

        while true
          ready_for = context.ready_for
          case ready_for
          when :ehlo
            SMTPServerCommandHandlers.ehlo(context)
          when :helo
            SMTPServerCommandHandlers.helo(context)
          when :re_ehlo
            SMTPServerCommandHandlers.ehlo(context, attempt_starttls: false)
          when :starttls
            SMTPServerCommandHandlers.starttls(context)
          when :mailfrom
            SMTPServerCommandHandlers.mailfrom(context)
          when :rcptto
            SMTPServerCommandHandlers.rcptto(context)
          when :data
            SMTPServerCommandHandlers.data(context)
          when :quit_positive
            SMTPServerCommandHandlers.quit(context)
            return true
          when :quit_negative
            SMTPServerCommandHandlers.quit(context, negative: true)
            return false
          end
        end
      end
    end
  end
end

      def self.ehlo(context, attempt_starttls: true)
        heloname = Config.active["mailname"] 
        command = SMTP::Command.new("EHLO", heloname)

        context.send_data(command)

        Logger.log "Self-Identified as `#{heloname}` with EHLO", origin: context.logger_origin, verbosity: 5

          end
          return true

          Logger.log "Server rejected EHLO with code `#{response.code}, trying HELO`", origin: context.logger_origin, verbosity: 5, type: :warn
          context.ready_for = :helo
          return false
        end
      end

module SMTPServer
  module Handlers
    module SMTPServerCommandHandlers
      def self.starttls(context)
        Logger.log "Attempting to upgrade to TLS", origin: context.logger_origin, verbosity: 5

        command = SMTP::Command.new("STARTTLS")
        context.send_data(command)

        response = context.read_response

        if response.code != "220"
          Logger.log "Server rejected STARTTLS request with code `#{response.code}`", origin: context.logger_origin, verbosity: 5, type: :warn
          context.ready_for = :mailfrom
          return
        end

        begin
          ssl_context = OpenSSL::SSL::SSLContext.new
          ssl_context.verify_mode = OpenSSL::SSL::VERIFY_NONE
          ssl_socket = OpenSSL::SSL::SSLSocket.new(context.tcp_server, ssl_context)
          ssl_socket.sync_close = true
          ssl_socket.connect

          context.server = ssl_socket

          Logger.log "Upgraded to TLS", origin: context.logger_origin, verbosity: 5

          context.ready_for = :re_ehlo
        rescue OpenSSL::SSL::SSLError
          Logger.log "Failed upgrading to TLS", origin: context.logger_origin, verbosity: 5, type: :warn

          context.ready_for = :mailfrom
        end
      end
    end
  end

### ./lib/mlsmtp/servers/mailserver.rb```
module SMTPServer
  module Servers
    class MailServer
      @@all_servers = []
      @@running_servers = []

      def initialize(host:, port:, encryption:, certificate:)
        @host = host
        @port = port
        @running = false
        @dead = false
        @pid = nil
        @encryption = encryption
        @certificate = certificate

        obj_id = self.object_id
        @origin = "Server #{obj_id}"

        @@all_servers << self
      end

      def start
        return false if @dead
        return true if @running

        @running = true
        @@running_servers << self

        @pid = fork do
          Signal.trap("INT", "IGNORE")

          begin
            Database.connect
            Logger.log "Successfully connected to database", origin: @origin, verbosity: 1
          rescue => e
            Logger.log "Error connecting to database", type: :error, origin: @origin
            raise e
          end

          tcp_server = TCPServer.new(@host, @port)
          
          if @encryption == :implicit
            context = @certificate.context
            server = OpenSSL::SSL::SSLServer.new(tcp_server, context)
          else
            server = tcp_server
          end

          Logger.log "Listening on #{@host}:#{@port}, encryption: #{@encryption}", origin: @origin, verbosity: 1

          while @running
            begin
              Thread.start(server.accept) do |client|
                client_ip = client.peeraddr[3]

                Logger.log "New connection from #{client_ip}", origin: @origin, verbosity: 2

                context = SMTP::SMTPClientContext.new(client)
                context.starttls_support = true if @encryption == :starttls
                context.starttls_certificate = @certificate&.context

                Logger.log "Creating SMTP client context for #{client_ip}", origin: @origin, verbosity: 3

                Logger.log "Handling client #{client_ip}", origin: @origin, verbosity: 3
                handler = Handlers::GenericClientHandler.new(context)
                handler.handle_client
              end
            rescue OpenSSL::SSL::SSLError
              Logger.log "SSL error for client", origin: @origin, verbosity: 2, type: :warn
            end
          end
        end

        return @pid
      end

      def restart
        stop
        sleep(Config.active["socket"]["restart_delay"])
        start
      end

      def stop(killcode: "TERM")
        Process.kill(killcode, @pid)
        @running = false
        @@running_servers.delete(self)

        Logger.log "Stopped server", origin: @origin, verbosity: 1
      end

      def kill
        stop
        @dead = true
        @@all_servers.delete(self)

        Logger.log "Killed server", origin: @origin, verbosity: 1
      end

      def self.all_servers
        @@all_servers
      end

      def self.running_servers
        @@running_servers
      end

      attr_reader :host, :port, :running, :dead, :pid
    end
  end
end

module SMTPServer
  module Email
    class ErrorEmailGenerator
      def initialize(error, origin:, mail_from:, rcpt_to:, is_error_response:)
        @error = error
        @origin = origin
        @mail_from = mail_from
        @rcpt_to = rcpt_to
        @is_error_response = is_error_response
      end

      def queue_email
        error = :other_internal
        error = "bad_mailbox" if @error.class == SMTPServer::Errors::NonexistentMailboxError
        error = "delivery_timeout" if @error.class == Timeout::Error
        error = "delivery_failed" if @error.class == SMTPServer::Errors::ServerRejectionError

        if error == :other_internal
          Logger.log "Unexpected error when delivering email: #{@error}", origin: @origin, verbosity: 3, type: :warn
        else
          Logger.log "Error delivering email: `#{@error}`", origin: @origin, verbosity: 3, type: :warn

          error_email = Email::ErrorEmail.new(
            original_from: @mail_from,
            original_to: @rcpt_to,
            email_name: error
          )

          err_email_text = error_email.prepared_email

          if @is_error_response == 0 && err_email_text
            queued_response = Queue::QueuedMessage.new(
              mail_from: Config.active["contact_email"],
              rcpt_to: @mail_from,
              message: err_email_text,
              error_response: true
            )

            id = queued_response.queue[1]

            Logger.log "Queued error response as `#{id}`", origin: @origin, verbosity: 4
          elsif @is_error_response == 1
            Logger.log "Original message was an error response; not sending another error response", origin: @origin, verbosity: 4
          end
        end
      end
    end
  end
